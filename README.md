# Cass à Vélo

Site vitrine : balades guidées et cours de vélo (enfants, seniors, mobilité réduite) autour de Grenoble.

En ligne : https://splintersteph.github.io/cass-velo/

- `index.html` accueil, `balades.html` carte des balades, `cours.html` programmes, `passeport.html` passeport Belle Via
- `donnees.js` : balades et étapes du passeport (tracés indicatifs)
- `site.js` : adresse de contact (EMAIL_CONTACT), carte, passeport
