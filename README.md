# Cass à Vélo

Site vitrine : balades guidées à vélo, cours pour enfants et remise en selle des seniors, à Grenoble.

En ligne : https://splintersteph.github.io/cass-velo/

- Pages : accueil, balades (carte), enfants, seniors, groupes, passeport Belle Via
- `donnees.js` : circuits, étapes du passeport, photos (aucune personne sans casque)
- `site.js` : adresse de contact (EMAIL_CONTACT), cartes, passeport, visionneuse
